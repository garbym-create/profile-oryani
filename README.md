# הפרופיל האורייני — כלי תמיכה בהחלטה

כלי למיפוי תלמידים לפי הפרופיל האורייני של משרד החינוך, המזכירות הפדגוגית — אגף שפות.

**הכלי אינו מחשב פרופיל ואינו מדרג.** הוא מציג את הממצאים שהמורה סימנה מול חמשת התיאורים הרשמיים, וההחלטה היא של המורה.

## שלושה שלבים

1. **מאפיינים** — סימון מצב התלמיד על חמישה צירים ובחמישה מאפיינים נוספים, וכן סימון ההיגדים בשני השאלונים הרפלקטיביים
2. **בחירת פרופיל** — לכל אחד מחמשת הפרופילים מוצגים המאפיינים שלו בניסוח הרשמי לצד הסימון של המורה
3. **מיקוד ההוראה** — המאפיינים שסומנו, מטרות הוראה, הצעות פדגוגיות והמלצות להתערבות, פרקטיקות, חומרי הוראה ומדדי תוצאה

## כלל ברזל

כל תוכן בכלי לקוח מילה במילה מן המסמכים הרשמיים. אין בו מדדים, סולמות דירוג או קריטריונים שאינם מופיעים במקור.

מספר האמירות בכל פרופיל תואם למסמך הרשמי: 8 / 5 / 4 / 4 / 3.

## הפעלה

קובץ HTML עצמאי אחד, ללא תלויות ובלי שמירת נתונים. נפתח ישירות בדפדפן.
